# Archived Experiment Scripts

These scripts are kept for reproducing older one-off experiments.

New experiments should use the JSON-driven entry points in the parent
directory:

```bash
python experiments/run_configured_strength.py --config experiments/config_strength_example.json
python experiments/run_configured_quality.py --config experiments/config_quality_example.json
```

Do not add new experiment variants here unless they are intentionally being
archived.
